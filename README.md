# intro-to-quant-program

A program that fetches stock signals from public data sources, combines them through a matrix of rules, and produces a report of stocks worth researching for short-term (days to weeks) trades.

It is also a learning project. Every signal is backtested on its own before it is trusted. A live practice portfolio, recorded in a markdown journal, runs alongside the code, so real outcomes can be compared against what the program would have said.

## Project documents

- [Problem statement](docs/PROBLEM_STATEMENT.md): what this project is trying to learn, why the last attempt struggled, and the approach
- [Research principles](docs/PRINCIPLES.md): the rules every signal, backtest, and trade is checked against
- [Signals guide](docs/SIGNALS.md): each signal, where its data comes from, how it works, and how strong the evidence is
- [Roadmap](docs/ROADMAP.md): the phased checklist, one session per box
- [Trading journal](journal/README.md): one markdown entry per check-in, with every trade's reasoning and outcome
