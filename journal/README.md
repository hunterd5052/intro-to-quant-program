# Journal

One file per check-in, named `YYYY-MM-DD-checkin-NN.md`. Each trade records:

1. **Trigger**: the event that started the idea
2. **Confirmation**: an independent signal from a different family
3. **Vetoes checked**: short interest and borrow fee, options skew, filing changes, attention spikes
4. **Exit plan**: price stop (on a closing basis) and time exit, set before entry
5. **Outcome**: return vs SPY over the same dates, and whether the plan was followed

Grade the process, not just the result. A well-reasoned loss is fine; a lucky win that broke the rules is not.
