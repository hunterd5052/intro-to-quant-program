# Logs

Backtest write-ups and run reports, as markdown. Every backtest gets a file here, including ones where the signal fails.

Each backtest write-up includes:

1. **Hypothesis**, written before running the test
2. **Data**: sources, date range, stocks, and how point-in-time dates were handled
3. **Method**: the event definition, holding windows, and benchmark (SPY)
4. **Results**: average excess return, hit rate, t-statistic, and number of events
5. **Costs and robustness**: results after costs, by sub-period, and by company size
6. **Verdict**: use it, use it only as a veto or confirmation, or drop it
